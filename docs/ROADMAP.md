# Roadmap

## v0.1: deterministic generator

Completed foundation:

- HNS delegated mode
- HNS SYNTH nameserver mode
- ICANN delegated mode
- TLSA 3 1 1 from PEM PUBLIC KEY
- TLSA 3 1 1 from PEM CERTIFICATE
- DS SHA-256 from DNSKEY
- Selectable plain-text output boxes
- Field-level setup hints

## v0.2 through v0.2.1: web-admin onboarding

Completed release scope:

- Setup status checklist
- Selectable parent, authoritative, verification, web, and integrator outputs
- Generic zone-file preset
- PowerDNS Authoritative preset
- Knot DNS preset
- BIND 9 preset
- NSD preset
- Docker/static deployment files
- Production deployment notes
- Web-admin guide
- Authoritative nameserver hardening guidance
- DNSSEC validation guidance for `delv`, AD-bit checks, and HNS-aware resolvers
- DNSSEC signing lifecycle and common validation failure notes
- TLSA key-rollover procedure
- Client-support and service-scope warnings

## v0.3: live validation

- Fetch live certificate and generate TLSA from host:port
- Automated DNSSEC chain check through a validating resolver
- TLSA live comparison
- Automated HNS parent record lookup
- Expiration and TTL warnings

## Linode appliance MVP (released by v0.2.1)

- Thin Linode/Akamai StackScript bootstrapper
- Versioned `appliance/` installer
- Canonical `/etc/hns-dane-appliance/config.json`
- Knot authoritative DNS with manual parent-facing DNSSEC rollover
- TLSA `3 1 1` from local HTTPS SPKI
- Beginner dashboard, public exports, verifier status, and root-only backups
- Single-node mode first
- Two-node reliable mode documented but not claimed complete

## v0.5: rollover workflows

- Current + next TLSA output generated by the app
- Certificate key rollover timeline
- DNSKEY / DS rollover timeline
- TTL-safe migration hints
- CDS/CDNSKEY advisory output

## v0.6: integrations

- Namehold embedded component
- HNS browser diagnostics component
- CLI package
- hsd/name resource JSON export
- Namebase/name-resource JSON export
